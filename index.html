このアプリについて

本アプリは、コンテンツのすべてをAIが生成する語学学習アプリです。 既存の英語学習アプリの多くは、あらかじめ用意された問題セットを繰り返す形式ですが、 本アプリでは問題・会話・記事・音声のすべてをAIがリアルタイムに生成します。

そのため、一人ひとりのレベル・弱点・学習履歴に合わせた内容を、 毎回異なる形で提供できます。同じ問題を何度も解くのではなく、 その人に必要な練習を、必要なタイミングで届ける設計です。

「オールAI」であることの意味

  • その人に特化した問題を出す — レベル・苦手分野・過去の間違いを踏まえて、毎回新しい問題を生成します
  • 個別に学習状況を管理する — 何を学んだか、どこでつまずいたかをAIが把握し、復習タイミングを最適化します
  • 傾向を把握する — 生徒ごとの正答率・弱点分野・学習頻度を可視化。指導にも活用できます

コンテンツをAIが生成するため、他の英語アプリが対応しているような学習領域 — 単語・文法・リスニング・英作文・会話など — はほぼ網羅できます。 問題をあらかじめ用意する必要がないので、新しいカテゴリや試験対策の追加も柔軟に行えます。

想定している学習者層

Duolingoの「その先」で苦労している方へ

Duolingoのような初級向けアプリで基礎を身につけた後、 「中級から上が伸びない」「実際の会話になると使えない」という壁にぶつかる学習者は少なくありません。

本アプリは、基礎を終えた学習者が、実践的な英語力を身につけるための練習環境として設計しています。 CEFR B1〜C1レベルを中心に、ビジネス英語・試験対策・日常会話を、 AIとの対話やドリルを通じて鍛えることができます。

貴社の教室に通う生徒さんが、授業の外でも効果的に練習できるツールとしてお役に立てればと考えています。

主な機能

現在実装済みの機能です。すべてAIによるリアルタイム生成で動作します。

💬

AIフリートーク

生徒のレベルに合わせてAIが自然な会話を行います。文法ミスのリアルタイム指摘、より良い表現の提案、音声入出力に対応しています。

📝

6種類のドリル

単語・イディオム・文法・構文・リスニング・英作文。CEFRレベルに応じた問題をAIが毎回異なる内容で生成します。

🃏

間隔反復フラッシュカード

間違えた問題は自動で復習カードに追加。SM-2アルゴリズムにより、忘れかけたタイミングで再出題されます。

📰

AIニュース記事

生徒のレベルに合わせた英語記事をAIが生成。長文読解と時事英語の両方を鍛えられます。

🎧

リスニング 3モード

ディクテーション・要点把握・シャドーイング。ネイティブ品質の音声合成で、聞き取り力を強化します。

🎙️

発音練習

音声認識を活用した発音練習機能です。

たとえば、こんなことができます

AIがコンテンツを生成するため、使い方の幅が広いのが特長です。

会話・スピーキング

  • AIとの英語フリートーク（テーマ自由、レベル自動調整）
  • 「カフェで注文する」「面接を受ける」などシーン別のロールプレイ
  • 会話中の文法ミスをリアルタイムで指摘、より自然な言い回しを提案
  • 音声入力で話しかけ、AIの返答も音声で聞ける
  • 生徒が言った内容をAIが添削し、模範文をフィードバック

語彙・文法

  • TOEIC / TOEFL / IELTS / 英検の頻出語彙を4択ドリルで出題
  • 過去に間違えた単語を優先的に再出題（弱点克服モード）
  • イディオム・句動詞の意味と使い方をドリル形式で学習
  • 時制・冠詞・前置詞など文法の穴を特定して集中練習
  • Duolingo風のドラッグ&ドロップ構文並べ替え練習
  • 間違えた問題は自動でフラッシュカードに追加、忘却曲線に沿って復習

リスニング・読解

  • ディクテーション — 音声を聞いて書き取り、AIが採点
  • 要点把握 — パッセージを聞いて、内容に合う要約を選択
  • シャドーイング — お手本音声に続いて復唱、音声認識で評価
  • 生徒のレベルに合わせた英語ニュース記事をAIが生成
  • 記事中のわからない単語をタップすると意味と例文を表示

英作文

  • AIが出題したテーマについて英語で文章を書く練習
  • 文法・語彙・構成の観点でAIが添削・採点
  • 「ビジネスメール」「エッセイ」「日記」など形式を選べる

学習管理・分析

  • 生徒ごとの学習時間・正答率・弱点分野を自動で記録
  • 「この生徒は前置詞が弱い」「リスニングの正答率が低い」など傾向を可視化
  • CEFRレベル（A1〜C2）に基づいた到達度の把握
  • 講師・保護者向けのダッシュボード画面で一覧管理

カスタマイズ例

  • 「今週のUnit 5の単語だけ出題してほしい」→ カリキュラム連動で対応
  • 「英検2級対策に特化したドリルがほしい」→ 試験モードで対応
  • 「教室のロゴとカラーでアプリを出したい」→ OEMブランディングで対応
  • 「生徒の進捗を保護者にメールで報告したい」→ ダッシュボード拡張で対応
  • 「小学生向けにやさしいUIにしたい」→ UIカスタマイズで対応

Duolingoはゲーム感覚で楽しく学べる一方、定型問題の繰り返しが中心で、中級以上の伸びには限界があります。 スタディサプリは質の高い講義コンテンツが強みですが、インタラクティブなAI会話機能はありません。 シャドテンはシャドーイング特化で発音改善に定評がありますが、月額が高く、会話練習やドリル機能はカバーしていません。 ChatGPTは会話の自由度は高いものの、体系的な学習管理・ドリル・復習機能がなく、学習アプリとしての設計はされていません。

本アプリは、これらのサービスが個別にカバーしている領域をAIによるコンテンツ生成で横断的に対応し、 さらに貴社の教室に特化したカスタマイズとOEM提供ができる点が特長です。

OEM提供について

このアプリをベースに、貴社の教室に合わせたカスタマイズが可能です。
AIネイティブで開発しているため、ご要望に応じた機能追加や調整を柔軟に行えます。

ブランディング

アプリ名・アイコン・カラーテーマを貴社のブランドに合わせて変更できます。App Storeへの公開も貴社名義で行えます。

カリキュラム連動

貴社の教材やテスト範囲に合わせたドリル設定が可能です。「今週はUnit 3の単語」といった指定もできます。

生徒管理ダッシュボード

生徒ごとの学習時間・正答率・弱点分野をWeb画面で一覧管理。保護者へのレポートにもご活用いただけます。

対象言語・レベルの調整

英語のみに限定する、特定のレベル帯に集中させるなど、貴社の教室に合った設定が可能です。

試験対策モード

英検・TOEIC・TOEFL・IELTSなど、生徒が目指す試験に合わせた問題を重点的に出題する設定が可能です。

その他の機能追加

AIネイティブの設計思想で開発しているため、「こういう機能がほしい」というご要望にも柔軟にお応えできます。
